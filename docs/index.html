fastBooking
Features GitHub Repo

Booking made blazingly fast.

A secure and scalable service for login-free appointment-booking for clients and managing said appointments as business owners. Powered by Spring Boot.

View on GitHub

Core Features

🛡️

Secure Authentication

Built-in JWT token management, encrypted passwords, and secure endpoint access using Spring Security.

🏢

Organization Management

Business owners can seamlessly register, manage their organizations, and track working hours.

✉️

Automated Emails

Integrated email service for sending welcome messages and notifications directly to your clients.

Built with modern tech

Java 21 Spring Boot 3 Hibernate & JPA PostgreSQL JUnit 5 & Mockito HTTP-Only JWT
