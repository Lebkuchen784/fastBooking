Learning journey:

JWT Authentication

Authentication by itself was an interesting topic to dive into.

I found that JSON Web Tokens (JWTs) are a modern, stateless way of doing authentication where the server/database do not save the user's authentication state internally and that authentication is handled on the client's side.

The challenging part was figuring out how to incorporate the JWT configuration and general spring authentication into my code.
The service class used for your users has to implement UserDetailsService, which then means your user class has to implement UserDetails, after the implementation and configuration, only then Spring has a way to go through your repository and check if provided login data is correct.

The JWT implementation itself is a lot of boiler plate code that you need to know where to include. The choice of HTTP-Only cookies was for improved security, specifically against XSS (cross site scripting) attacks where malicious JS code can read browser cookies and steal them using javascript.

Frontend

I had little experience with frontend development before, so working with raw HTML, JavaScript, and Thymeleaf was new to me.

I found that Thymeleaf uses a special syntax, namely wrapping statements in ||, which allows you to mix strings and variables without the typical string concatenation.

The frontend integration itself required a good amount of trial and error, trying to figure out how to pass IDs and things from the frontend to the backend. Thymeleaf makes your life as a frontend developer much easier especially with the integrated loops.
